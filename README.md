# joel-portfolio

Personal portfolio site for Joel Thomas — built with Next.js, React, Tailwind CSS, and Framer Motion.

## Getting started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `pnpm dev` — start development server
- `pnpm build` — production build
- `pnpm start` — serve production build
